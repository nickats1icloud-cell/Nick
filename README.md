# Nick — Ψηφιακό Καντράν, Εργαστήριο Κατασκευών & Ραδιοφωνικός Προπονητής

React + Vite εφαρμογή με τρία εργαλεία:

- **`/dashboard`** — ένα πλήρως λειτουργικό ψηφιακό καντράν αυτοκινήτου (digital
  instrument cluster) εμπνευσμένο από το LCD καντράν του Honda Civic EK.
- **`/lab`** — εργαστήριο sim racing κατασκευών με Arduino: βιβλιοθήκη
  εξαρτημάτων, καλωδίωση, έλεγχος σχεδίασης, εικονικό test με πραγματική
  συμπεριφορά και γεννήτρια κώδικα.
- **`/podcast`** — ανάλυση ελληνόφωνου sim racing podcast από RSS feed και
  απομαγνητοφώνηση, με βαθμολογίες και συγκεκριμένες συμβουλές παρουσίασης.

## Εργαστήριο κατασκευών (`/lab`)

Σαν το SimHub αλλά ανάποδα: αντί να συνδέσεις υπάρχον υλικό στο παιχνίδι,
**χτίζεις** την κατασκευή από πραγματικά εξαρτήματα και τη **δοκιμάζεις εικονικά**
πριν παραγγείλεις τίποτα. Όλα τρέχουν στον browser.

- **Βιβλιοθήκη εξαρτημάτων** — 7 πλακέτες (Pro Micro, Leonardo, Nano, Uno, Pico,
  ESP32, Teensy 4.1) και ~30 εξαρτήματα με πραγματικά χαρακτηριστικά: κουμπιά,
  encoders, matrix, Hall, ποτενσιόμετρα, load cells, HX711, ADS1115, MCP23017,
  WS2812, OLED/TFT/Nextion, TM1637, βηματικοί δείκτες X27.168, σέρβο,
  ανεμιστήρες, haptics, MOSFET, buck, level shifter, δίοδοι.
- **Πάγκος καλωδίωσης** — σύρε τις κάρτες, κλικ σε δύο pins για καλώδιο, κλικ σε
  καλώδιο για διαγραφή. Τα καλώδια δρομολογούνται ορθογώνια σαν πραγματική
  δεσμίδα και παρακάμπτουν τις κάρτες αντί να περνούν από κάτω τους· επιλέγοντας
  ένα εξάρτημα φωτίζονται τα δικά του και σβήνουν τα υπόλοιπα. Το κουμπί
  «Τακτοποίηση» βάζει κάθε εξάρτημα στη μεριά της πλακέτας που του αντιστοιχεί. Τα pins κάθε πλακέτας είναι τα πραγματικά, με τη σειρά
  και τα ονόματα που τυπώνονται πάνω της (RAW/VCC στο Pro Micro, VBUS/VSYS στο
  Pico, IOREF/AREF στο Leonardo), και στη μέση της κάρτας η ίδια η πλακέτα
  ζωγραφισμένη στις πραγματικές της αναλογίες — κόκκινο Pro Micro, πράσινο Pico
  με BOOTSEL, μακρύ Teensy, θωρακισμένο ESP32.
- **Καλωδίωση σε δική της καρτέλα** (`/lab/wiring`) — ο πάγκος με όλο το πλάτος
  και ύψος της οθόνης, με zoom (`Ctrl`+ροδέλα, `+`/`−`, `0` να χωρέσουν όλα) και
  μετακίνηση σέρνοντας το φόντο. Μοιράζεται την κατασκευή με το `/lab` ζωντανά:
  ό,τι αλλάζεις στη μία καρτέλα εμφανίζεται στην άλλη. Το καλώδιο που τραβάς
  ακολουθεί τον δείκτη, τα συμβατά pins φωτίζονται πράσινα και τα ασύμβατα
  σβήνουν, το `Esc` ακυρώνει, το `Del` σβήνει το επιλεγμένο εξάρτημα, και το
  `Ctrl+Z` / `Ctrl+Shift+Z` αναιρεί και επαναλαμβάνει (έως 60 βήματα).
- **Πάνελ** — δεύτερη όψη του πάγκου όπου τα εξαρτήματα είναι πραγματικά
  χειριστήρια: πατάς το κουμπί και βυθίζεται, γυρίζεις τον encoder σέρνοντας,
  τραβάς το πεντάλ και ανεβαίνει η δύναμη σε κιλά, ενώ οι έξοδοι (rev lights,
  οθόνη, γρανάζι, όργανο) ζωντανεύουν δίπλα τους.
- **Έλεγχος σχεδίασης** — analog σε ψηφιακό pin, σύγκρουση pins, διπλή διεύθυνση
  I2C, φορτίο απευθείας σε pin χωρίς MOSFET, WS2812 με λογική 3.3V, load cell
  χωρίς ενισχυτή, υπέρβαση ρεύματος USB, ασύνδετο GND τροφοδοτικού, RAM/flash
  εκτός ορίων. Κάθε εύρημα δίνει τη συγκεκριμένη διόρθωση.
- **Πραγματικό test** — αναπήδηση επαφών και ψεύτικα πατήματα χωρίς debounce,
  θόρυβος και κβαντισμός ADC, χαμένα βήματα encoder σε αργό βρόχο, πτώση τάσης
  και reset όταν η ταινία LED τραβάει πάνω από το USB, κατανάλωση υπολογισμένη
  από τα χρώματα που ανάβουν εκείνη τη στιγμή.
- **Προϋπολογισμός βρόχου** — πόσα µs τρώει κάθε εξάρτημα και πού πέφτει η
  συχνότητα του `loop()` (μια οθόνη OLED σε I2C με πλήρες frame κοστίζει 23ms).
- **Εικονικό αυτοκίνητο** — τρεις πίστες με αυτόματο οδηγό (στροφές, γρανάζι,
  ABS, ολίσθηση, κράσπεδα, καύσιμο, χρόνοι γύρου, delta, σημαίες) ή χειροκίνητα
  χειριστήρια, για να τροφοδοτούνται οι έξοδοι.
- **Βιβλιοθήκες Arduino** — μητρώο πραγματικών βιβλιοθηκών (Joystick, FastLED,
  HX711, Bounce2, Encoder, Keypad, Adafruit SSD1306/ILI9341/ADS1X15/MCP23017,
  TM1637, SwitecX25, TinyUSB, ESP32-BLE-Gamepad) με έκδοση, σύνδεσμο, εντολή
  `arduino-cli` και κόστος σε flash/RAM.
- **Γεννήτρια κώδικα** — έτοιμο σκίτσο `.ino` με τα ίδια pins και ρυθμίσεις που
  δοκίμασες, μαζί με το template τηλεμετρίας για SimHub Custom Serial Devices.
  Η κεφαλίδα λέει ποια πλακέτα να διαλέξεις στο IDE, ποιες βιβλιοθήκες να
  εγκαταστήσεις, την εντολή `arduino-cli compile --fqbn …`, και με ποιο όνομα
  φακέλου να το αποθηκεύσεις (το IDE δεν δέχεται ελληνικά ονόματα σκίτσων).
- **Λίστα υλικών** — κόστος ανά εξάρτημα και ανά εντολή, με εξαγωγή CSV.
- **8 έτοιμες κατασκευές** — button box, πεντάλ φρένου, rev lights, sequential
  shifter, wind simulator, πλήρες καντράν, χειρόφρενο, πάνελ 16 κουμπιών.

## Το καντράν (`/dashboard`)

- **Στροφόμετρο & ταχύμετρο** — αναλογικά SVG όργανα με βελόνα, υποδιαιρέσεις και ζώνη redline.
- **Κεντρική ψηφιακή οθόνη** — ταχύτητα, σχέση μετάδοσης (gear), odometer & trip.
- **Δευτερεύοντα όργανα** — θερμοκρασία νερού, καύσιμο, boost (turbo), πίεση λαδιού, τάση μπαταρίας.
- **Warning lights** — φλας, μεγάλη σκάλα, χειρόφρενο, λάδι, μπαταρία, υπερθέρμανση, καύσιμο, check engine, ABS.
- **Μηχανή προσομοίωσης** — «οδήγησε» με γκάζι/φρένο και αυτόματο κιβώτιο· όλα τα όργανα αντιδρούν ζωντανά.

### Έλεγχοι

| Πλήκτρο            | Λειτουργία        |
| ------------------ | ----------------- |
| `↑` / `W`          | Γκάζι             |
| `↓` / `S`          | Φρένο             |
| `A` / `D`          | Φλας αρ./δεξ.     |
| `H`                | Μεγάλη σκάλα      |
| `P`                | Χειρόφρενο        |

Υπάρχουν και on-screen κουμπιά (γκάζι/φρένο/διακόπτες) για χρήση με ποντίκι ή αφή.

## Ραδιοφωνικός προπονητής (`/podcast`)

Εργαλείο για podcaster: δίνεις το **RSS feed** του podcast και (προαιρετικά) την
**απομαγνητοφώνηση** ενός επεισοδίου, και παίρνεις μετρήσεις και συμβουλές. Όλα
τρέχουν τοπικά στον browser — κανένα δεδομένο δεν ανεβαίνει πουθενά.

**Από το feed:** συνέπεια δημοσιεύσεων (διάμεσο κενό, μεγαλύτερο κενό, μέρα
εβδομάδας), σταθερότητα διάρκειας, μήκος και μοτίβα τίτλων, ποιότητα shownotes
(λέξεις, κεφάλαια, σύνδεσμοι), metadata (αριθμός επεισοδίου, γλώσσα, εικόνα) και
λέξεις-κλειδιά που «βλέπει» η αναζήτηση.

**Από την απομαγνητοφώνηση** (`.srt`, `.vtt` ή σκέτο κείμενο):

- ρυθμός ομιλίας (λέξεις/λεπτό, συλλαβές/δευτ.),
- παρασιτικά ελληνικά (`εεε`, `βασικά`, `δηλαδή`, `ας πούμε`, `λοιπόν`,
  υπεκφυγές τύπου `νομίζω`/`μάλλον`) με χρονογραμμή ανά λεπτό,
- μήκος προτάσεων και επαναλαμβανόμενες φράσεις,
- ερωτήσεις (πόσες, πόσες ανοιχτές),
- ισορροπία ομιλητών και μεγαλύτερος μονόλογος,
- νεκρός χρόνος/παύσεις, αγγλισμοί vs ορολογία sim racing, ποιότητα ανοίγματος
  και κλεισίματος.

Κάθε βαθμολογία συνοδεύεται από συμβουλές με άσκηση, υπάρχει εξαγωγή αναφοράς σε
Markdown και ιστορικό αναλύσεων για να φαίνεται η πρόοδος ανά επεισόδιο.

Το RSS διαβάζεται απευθείας από τον browser· αν το μπλοκάρει το CORS, η σελίδα
δοκιμάζει δημόσιους proxies και τελικά δέχεται επικόλληση του XML με το χέρι.

## Stack

- [React 18](https://react.dev)
- [Vite 5](https://vitejs.dev)
- [React Router 6](https://reactrouter.com)
- ESLint

## Εκκίνηση

```bash
npm install
npm run dev
```

Άνοιξε [http://localhost:5173](http://localhost:5173).

## Εντολές

| Εντολή            | Περιγραφή                          |
| ----------------- | ---------------------------------- |
| `npm run dev`     | Dev server με hot reload           |
| `npm run build`   | Production build στο `dist/`       |
| `npm run preview` | Προεπισκόπηση του production build  |
| `npm run lint`    | Έλεγχος κώδικα με ESLint           |

## Δομή

```
.
├── index.html
├── vite.config.js
├── eslint.config.js
└── src
    ├── main.jsx          # Entry point + router
    ├── App.jsx           # Ορισμός routes
    ├── index.css         # Global styles + design tokens
    ├── components/       # Layout, Navbar, Footer, dashboard/, podcast/
    ├── hooks/            # useVehicleSim (προσομοίωση οχήματος)
    ├── lib/              # ανάλυση podcast: RSS, transcript, ελληνικά, scoring
    └── pages/            # Home, Dashboard, Podcast, About, NotFound
```

## Πώς να επεκταθεί

- Νέα σελίδα: φτιάξε ένα component στο `src/pages/` και πρόσθεσέ το ως `<Route>` στο `src/App.jsx`.
- Νέο link στο menu: πρόσθεσε ένα `<NavLink>` στο `src/components/Navbar.jsx`.
- Styling: τα design tokens (χρώματα, radius κ.λπ.) ορίζονται ως CSS variables στην κορυφή του `src/index.css`.
