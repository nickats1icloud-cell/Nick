# Nick — Race Control, Ψηφιακό Καντράν & Ραδιοφωνικός Προπονητής

React + Vite εφαρμογή με τρία εργαλεία:

- **`/championship`** — **Race Control**: management system για πρωτάθλημα
  αντοχής στο Le Mans Ultimate. Ομάδες, αρχηγοί, οδηγοί, καλεντάρι, πλάνα stint
  με έλεγχο κανονισμού, αποτελέσματα και βαθμολογίες.
- **`/dashboard`** — ένα πλήρως λειτουργικό ψηφιακό καντράν αυτοκινήτου (digital
  instrument cluster) εμπνευσμένο από το LCD καντράν του Honda Civic EK.
- **`/podcast`** — ανάλυση ελληνόφωνου sim racing podcast από RSS feed και
  απομαγνητοφώνηση, με βαθμολογίες και συγκεκριμένες συμβουλές παρουσίασης.

## Race Control (`/championship`)

Ολοκληρωμένο σύστημα διαχείρισης πρωταθλήματος αντοχής για το **Le Mans
Ultimate** — Hypercar, LMP2, LMGT3 και GTE, με το πραγματικό περιεχόμενο του
παιχνιδιού (11 πίστες, αυτοκίνητα ανά κατηγορία).

### Ρόλοι

| Ρόλος            | Τι μπορεί να κάνει                                                                    |
| ---------------- | ------------------------------------------------------------------------------------- |
| **Διοργανωτής**  | Όλα: καλεντάρι, ομάδες, κανόνες, βαθμολογία, αποτελέσματα, έγκριση πλάνων             |
| **Αρχηγός ομάδας** | Roster της ομάδας του, πλάνα stint, διαθεσιμότητες, υποβολή πλάνου προς έγκριση     |
| **Οδηγός**       | Βλέπει τα πλάνα της ομάδας του και δηλώνει τη δική του διαθεσιμότητα                  |
| **Επισκέπτης**   | Μόνο ανάγνωση                                                                         |

Η «σύνδεση» γίνεται με επιλογή ταυτότητας από τη λίστα του πρωταθλήματος. Δεν
υπάρχει server ούτε κωδικοί: τα δικαιώματα εφαρμόζονται στο UI για να οργανωθεί
η δουλειά της ομάδας, **δεν** είναι μηχανισμός ασφαλείας.

### Stint planner

Ο πυρήνας του συστήματος. Για κάθε ομάδα και αγώνα:

- **Χρονογραμμή αγώνα** με χρώμα ανά οδηγό, στάσεις, και τη γραμμή τερματισμού.
- **Τεχνικά στοιχεία αυτοκινήτου** ανά πίστα (ρεζερβουάρ, κατανάλωση, χρόνος
  γύρου, ζωή ελαστικών) — προτείνονται από κατηγορία + πίστα και διορθώνονται.
- **Υπολογισμοί ανά stint**: ώρα αγώνα, διάρκεια, λίτρα, τι μένει στο ρεζερβουάρ,
  σετ ελαστικών, χρόνος στάσης (pit loss + ρεφιουλάρισμα / αλλαγή οδηγού /
  αλλαγή ελαστικών).
- **Αυτόματο πλάνο** που καλύπτει τη διάρκεια του αγώνα, κάνει διπλό stint στα
  ελαστικά όπου αντέχουν, και μοιράζει τους διαθέσιμους οδηγούς σεβόμενο
  ξεκούραση και πλαφόν χρόνου.
- **Φόρτος οδηγών**: πόσο οδηγεί ο καθένας, ποσοστό αγώνα, μέγιστο σερί,
  ελάχιστη ξεκούραση.
- **Ροή έγκρισης**: Πρόχειρο → Υποβλήθηκε → Εγκρίθηκε / Θέλει αλλαγές.
- **Εξαγωγή** σε Markdown (για Discord/εκτύπωση στο pit) και CSV.

### Μηχανή κανόνων

Κάθε αλλαγή στο πλάνο ελέγχεται ζωντανά. Οι κανόνες ρυθμίζονται από τον
διοργανωτή στη Διαχείριση:

- κάλυψη της διάρκειας του αγώνα,
- μέγιστη **συνεχόμενη** οδήγηση (η στάση δεν μηδενίζει τον χρόνο οδήγησης),
- ελάχιστη ξεκούραση μεταξύ βαρδιών,
- πλαφόν % του αγώνα ανά οδηγό και ελάχιστος χρόνος ανά δηλωμένο οδηγό,
- ελάχιστος χρόνος για Silver/Bronze (κανόνας Am),
- ελάχιστοι/μέγιστοι οδηγοί ανά αυτοκίνητο,
- καύσιμα ανά stint vs ρεζερβουάρ, ζωή ελαστικών, σύνολο σετ ανά αγώνα,
- roster και δηλωμένη διαθεσιμότητα, deadline υποβολής.

Το πλάνο **δεν υποβάλλεται** όσο υπάρχουν σφάλματα.

### Βαθμολογίες

Βαθμοί με βάση τη θέση **στην κατηγορία**, ξεχωριστοί πίνακες ομάδων και
οδηγών, βαθμός pole και γρηγορότερου γύρου, ελάχιστο ποσοστό γύρων του νικητή
για βαθμολόγηση, διπλοί βαθμοί σε επιλεγμένους αγώνες (π.χ. Le Mans), drop
rounds και λύση ισοβαθμίας με νίκες/καλύτερες θέσεις. Εξαγωγή σε Markdown.

### Δεδομένα & backend

Η εφαρμογή τρέχει σε δύο λειτουργίες, με **ίδιο ακριβώς UI**:

| | Τοπική (προεπιλογή) | Με backend (Supabase) |
| --- | --- | --- |
| Αποθήκευση | `localStorage` του browser | Postgres |
| Σύνδεση | επιλέγεις ποιος είσαι από λίστα | email + κωδικός |
| Δικαιώματα | μόνο στο UI | **Row Level Security στη βάση** |
| Πολλοί χρήστες | όχι (backup/restore σε JSON) | ναι, με realtime |

Στο πρώτο άνοιγμα της τοπικής λειτουργίας φορτώνεται πρωτάθλημα **επίδειξης**
(11 ομάδες, 6 αγώνες, 3 ολοκληρωμένοι, έτοιμα πλάνα).

#### Ενεργοποίηση backend

1. Φτιάξε project στο [Supabase](https://supabase.com) (το free tier αρκεί).
2. SQL Editor → τρέξε ολόκληρο το `supabase/migrations/001_championship.sql`.
3. `cp .env.example .env.local` και βάλε `VITE_SUPABASE_URL` /
   `VITE_SUPABASE_ANON_KEY` (Project Settings → API).
4. `npm run dev` — η εφαρμογή περνά μόνη της σε λειτουργία backend.
5. Κάνε λογαριασμό από το «Σύνδεση» και μετά, στη **Διαχείριση → Backend**,
   είτε φτιάξε κενό πρωτάθλημα είτε **ανέβασε το τοπικό/demo** στο cloud.

Το anon key είναι σχεδιασμένο να είναι δημόσιο — την πρόσβαση την κρίνει το RLS.
Το `service_role` key **δεν** μπαίνει ποτέ στο frontend.

#### Τι επιβάλλει η βάση (όχι το UI)

- Ο **αρχηγός** γράφει μόνο στην ομάδα του: roster, πλάνα, διαθεσιμότητες.
- Το **εγκεκριμένο πλάνο κλειδώνει** — ούτε ο αρχηγός το αλλάζει, ούτε το
  εγκρίνει μόνος του (`lmu_guard_plan`).
- Τα **πλάνα stint είναι μυστικά**: τα βλέπει μόνο η ομάδα τους και η
  διοργάνωση. Οι υπόλοιποι δεν παίρνουν καν τις γραμμές.
- Ο **οδηγός** αλλάζει μόνο τα προσωπικά του και τη δική του διαθεσιμότητα —
  όχι κατηγορία, ρόλο ή ομάδα (`lmu_guard_driver`).
- Ο **οδηγός ενός stint** πρέπει να ανήκει στην ομάδα του πλάνου.
- **Επισκέπτες** βλέπουν καλεντάρι, ομάδες, αποτελέσματα και βαθμολογίες. Τα
  emails δεν εκτίθενται: το δημόσιο roster περνά από view (`v_public_drivers`).

Η σύνδεση λογαριασμού με τον οδηγό γίνεται με το **email**: ο αρχηγός το γράφει
στο roster και, μόλις ο οδηγός φτιάξει λογαριασμό με το ίδιο email, παίρνει
αυτόματα τα δικαιώματά του (trigger `lmu_link_driver_on_signup`, με κουμπί
«Βρες τη θέση μου» για την αντίστροφη σειρά).

## Το καντράν (`/dashboard`)

- **Στροφόμετρο & ταχύμετρο** — αναλογικά SVG όργανα με βελόνα, υποδιαιρέσεις και ζώνη redline.
- **Κεντρική ψηφιακή οθόνη** — ταχύτητα, σχέση μετάδοσης (gear), odometer & trip.
- **Δευτερεύοντα όργανα** — θερμοκρασία νερού, καύσιμο, boost (turbo), πίεση λαδιού, τάση μπαταρίας.
- **Warning lights** — φλας, μεγάλη σκάλα, χειρόφρενο, λάδι, μπαταρία, υπερθέρμανση, καύσιμο, check engine, ABS.
- **Μηχανή προσομοίωσης** — «οδήγησε» με γκάζι/φρένο και αυτόματο κιβώτιο· όλα τα όργανα αντιδρούν ζωντανά.

### Έλεγχοι

| Πλήκτρο            | Λειτουργία        |
| ------------------ | ----------------- |
| `↑` / `W`          | Γκάζι             |
| `↓` / `S`          | Φρένο             |
| `A` / `D`          | Φλας αρ./δεξ.     |
| `H`                | Μεγάλη σκάλα      |
| `P`                | Χειρόφρενο        |

Υπάρχουν και on-screen κουμπιά (γκάζι/φρένο/διακόπτες) για χρήση με ποντίκι ή αφή.

## Ραδιοφωνικός προπονητής (`/podcast`)

Εργαλείο για podcaster: δίνεις το **RSS feed** του podcast και (προαιρετικά) την
**απομαγνητοφώνηση** ενός επεισοδίου, και παίρνεις μετρήσεις και συμβουλές. Όλα
τρέχουν τοπικά στον browser — κανένα δεδομένο δεν ανεβαίνει πουθενά.

**Από το feed:** συνέπεια δημοσιεύσεων (διάμεσο κενό, μεγαλύτερο κενό, μέρα
εβδομάδας), σταθερότητα διάρκειας, μήκος και μοτίβα τίτλων, ποιότητα shownotes
(λέξεις, κεφάλαια, σύνδεσμοι), metadata (αριθμός επεισοδίου, γλώσσα, εικόνα) και
λέξεις-κλειδιά που «βλέπει» η αναζήτηση.

**Από την απομαγνητοφώνηση** (`.srt`, `.vtt` ή σκέτο κείμενο):

- ρυθμός ομιλίας (λέξεις/λεπτό, συλλαβές/δευτ.),
- παρασιτικά ελληνικά (`εεε`, `βασικά`, `δηλαδή`, `ας πούμε`, `λοιπόν`,
  υπεκφυγές τύπου `νομίζω`/`μάλλον`) με χρονογραμμή ανά λεπτό,
- μήκος προτάσεων και επαναλαμβανόμενες φράσεις,
- ερωτήσεις (πόσες, πόσες ανοιχτές),
- ισορροπία ομιλητών και μεγαλύτερος μονόλογος,
- νεκρός χρόνος/παύσεις, αγγλισμοί vs ορολογία sim racing, ποιότητα ανοίγματος
  και κλεισίματος.

Κάθε βαθμολογία συνοδεύεται από συμβουλές με άσκηση, υπάρχει εξαγωγή αναφοράς σε
Markdown και ιστορικό αναλύσεων για να φαίνεται η πρόοδος ανά επεισόδιο.

Το RSS διαβάζεται απευθείας από τον browser· αν το μπλοκάρει το CORS, η σελίδα
δοκιμάζει δημόσιους proxies και τελικά δέχεται επικόλληση του XML με το χέρι.

## Stack

- [React 18](https://react.dev)
- [Vite 5](https://vitejs.dev)
- [React Router 6](https://reactrouter.com)
- [Supabase](https://supabase.com) — προαιρετικό backend για το `/championship`
  (φορτώνεται lazy: χωρίς ρύθμιση δεν κατεβαίνει καν στον browser)
- ESLint

## Εκκίνηση

```bash
npm install
npm run dev
```

Άνοιξε [http://localhost:5173](http://localhost:5173).

| Εντολή            | Περιγραφή                          |

## Δομή

```
.
├── index.html
├── vite.config.js
├── eslint.config.js
└── src
    ├── main.jsx          # Entry point + router
    ├── App.jsx           # Ορισμός routes
    ├── index.css         # Global styles + design tokens
    ├── components/       # Layout, Navbar, Footer, dashboard/, podcast/, champ/
    ├── hooks/            # useVehicleSim (όχημα), useChampionship (πρωτάθλημα)
    ├── lib/
    │   ├── (podcast)     # RSS, transcript, ελληνικά, scoring
    │   └── lmu/          # πρωτάθλημα: model, store, stints, rules, standings
    │                     # + backend: config, supabase, api, auth
    └── pages/            # Home, Dashboard, Podcast, About, champ/, NotFound

supabase/
└── migrations/
    └── 001_championship.sql   # πίνακες, RLS, triggers, RPC
```

## Πώς να επεκταθεί

- Νέα σελίδα: φτιάξε ένα component στο `src/pages/` και πρόσθεσέ το ως `<Route>` στο `src/App.jsx`.
- Νέο link στο menu: πρόσθεσε ένα `<NavLink>` στο `src/components/Navbar.jsx`.
- Styling: τα design tokens (χρώματα, radius κ.λπ.) ορίζονται ως CSS variables στην κορυφή του `src/index.css`.
