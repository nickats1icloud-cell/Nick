# 02 — Job System

## Η θεμελιώδης διάκριση

**Το Job System είναι ανεξάρτητο από το Business Management.** Είναι δύο
ξεχωριστά gameplay layers και δεν επικοινωνούν παρά μόνο μέσω του συμβολαίου.

Όταν ο παίκτης είναι **εργαζόμενος**:

| Δεν | Ναι |
| --- | --- |
| δεν διαχειρίζεται την εταιρεία | λαμβάνει μία εργασία από τον εργοδότη |
| δεν προσλαμβάνει άλλους | χρησιμοποιεί employer-owned υλικά |
| δεν ελέγχει το company bank account | εκτελεί συγκεκριμένα βήματα |
| δεν αγοράζει stock με δικά του χρήματα | περνά quality control |
| δεν βλέπει τα κέρδη της εταιρείας | λαμβάνει **προσωπικό** μισθό και career XP |

Αυτή η διάκριση είναι ο λόγος που το παιχνίδι δεν καταρρέει σε «όλοι έχουν
εταιρεία». Ο εργαζόμενος δεν είναι μικρός επιχειρηματίας· είναι εργαζόμενος.

**Ένας χαρακτήρας δεν μπορεί να εργάζεται ταυτόχρονα σε δύο εταιρείες.** Αυτό
επιβάλλεται στη βάση: unique constraint σε `(character_id)` στα ενεργά
`employment_contracts`.

## Το συμβόλαιο

Κάθε δουλειά έχει:

| Πεδίο | Νόημα |
| ----- | ----- |
| `employer_id` | ποια επιχείρηση (ή AI εργοδότης) |
| `role` | ειδικότητα, από τον κατάλογο παρακάτω |
| `required_xp` | κατώφλι εισόδου στην ειδικότητα |
| `shift` | ωράριο: ποιες ώρες της ημέρας μπορείς να δουλέψεις |
| `energy_cost` | ενέργεια ανά task |
| `pay_rate` | αμοιβή βάσης ανά ολοκληρωμένο task |
| `quality_bonus` | ποσοστό επί του `pay_rate` ανάλογα με το score |
| `probation` | περίοδος όπου κακή ποιότητα λύνει το συμβόλαιο |

## Ο βρόχος της εργασίας

```
job board → αίτηση → συμβόλαιο → βάρδια
                                    │
                                    ▼
                        ┌── ανάθεση task ──┐
                        │   (employer      │
                        │    materials)    │
                        ▼                  │
                    βήματα 1..n            │
                        │                  │
                        ▼                  │
                  quality control          │
                     ╱        ╲            │
                 pass          fail        │
                   │             │         │
        μισθός + XP        rework ή scrap  │
                   │             │         │
                   └──► ιστορικό ◄─┘       │
                        │                  │
                        └── ενέργεια > 0 ──┘
```

### Βήματα (tasks)

Ένα task **δεν** είναι progress bar. Είναι μια σειρά από βήματα όπου ο παίκτης
κάνει επιλογή ή ενέργεια, και κάθε βήμα συνεισφέρει στο τελικό quality score.
Παραδείγματα ανά τύπο βήματος:

- **Επιλογή** — ποιο μέγεθος ελαστικού, ποια ροπή, ποιο υλικό. Λάθος επιλογή =
  ποινή ποιότητας, όχι αποτυχία.
- **Ακρίβεια** — τοποθέτηση σε σωστή θέση/τιμή μέσα σε ανοχή (π.χ. balancing).
- **Ακολουθία** — σωστή σειρά (π.χ. σταυρωτό σφίξιμο μπουλονιών).
- **Χρόνος** — βήμα με παράθυρο (π.χ. pit stop, cure time χημικού).

Ο κανόνας: **κάθε ειδικότητα έχει τουλάχιστον δύο διαφορετικούς τύπους
βημάτων**, αλλιώς όλες οι δουλειές παίζονται ίδια.

### Quality control

```
quality = clamp01( Σ(step_score × step_weight)
                   × skill_factor(xp)
                   × condition_factor(energy, stress)
                   × tool_factor(εξοπλισμός εργοδότη) )
```

| Ζώνη | Αποτέλεσμα |
| ---- | ---------- |
| ≥ 0.90 | Άριστο: πλήρης μισθός + bonus, XP ×1.25, φήμη εργοδότη ↑ |
| 0.70–0.89 | Αποδεκτό: πλήρης μισθός, XP ×1.0 |
| 0.50–0.69 | Rework: το task επαναλαμβάνεται με μισό `energy_cost`, χωρίς επιπλέον μισθό |
| < 0.50 | Scrap: τα υλικά του εργοδότη χάνονται, κανένας μισθός, XP ×0.25, στίγμα στο ιστορικό |

Το scrap **πρέπει** να κοστίζει στον εργοδότη πραγματικά υλικά. Αυτό είναι που
κάνει την πρόσληψη απόφαση με ρίσκο, άρα το reputation του εργαζομένου νόμισμα.

## Ιστορικό εργασίας

Κάθε ολοκληρωμένο task γράφει εγγραφή: εργοδότης, ρόλος, ημερομηνία, quality,
αμοιβή. Το ιστορικό είναι **δημόσιο προς υποψήφιους εργοδότες** (μέσος όρος
ποιότητας, συνέπεια, πόσα συμβόλαια έληξαν πρόωρα). Είναι το βιογραφικό του
χαρακτήρα και ο λόγος που ο παίκτης νοιάζεται για την ποιότητα και όχι μόνο
για τον όγκο.

## Ειδικότητες

### Γενικά επαγγέλματα

Συνεργεία, καταστήματα, fabrication, logistics. Είναι η είσοδος στο παιχνίδι:
χαμηλό `required_xp`, χαμηλή αμοιβή, απλά βήματα, και τροφοδοτούν την
παραγωγή των επιχειρήσεων.

### Οι 10 motorsport ειδικότητες

| Ειδικότητα | Κύρια βήματα | Τροφοδοτεί |
| ---------- | ------------ | ---------- |
| Tyre technician | επιλογή γόμας, πίεση, balancing, θερμοκρασία | race prep, tire shop |
| Junior race mechanic | ροπές, ακολουθία, έλεγχος διαρροών | συντήρηση, pit |
| Fabrication assistant | κοπή/συγκόλληση σε ανοχή, υλικό | fabrication chain |
| Transporter driver | διαδρομή, χρόνος, ασφάλεια φορτίου | logistics |
| Data assistant | ανάγνωση telemetry, εντοπισμός ανωμαλίας | setup ομάδας |
| Track marshal | αντίδραση σε συμβάν, σωστή σημαία | events |
| Team spotter | timing, πληροφορία στον οδηγό | αγώνας |
| Scrutineering assistant | checklist συμμόρφωσης, μετρήσεις | technical inspection |
| Livery preparation technician | προετοιμασία επιφάνειας, ευθυγράμμιση, cure time | car care, χορηγοί |
| Pit crew member | ακολουθία + χρονικό παράθυρο υπό πίεση | αγώνας |

Οι motorsport ειδικότητες δεν είναι απλώς «καλύτερα πληρωμένες». Είναι ο
δρόμος με τον οποίο ένας παίκτης μπαίνει στον χώρο του αγωνιστικού χωρίς να
έχει δικό του αυτοκίνητο: δουλεύεις στο pit κάποιου άλλου και μαθαίνεις.

## AI εργοδότες

Σε χαμηλό population, AI επιχειρήσεις δημοσιεύουν θέσεις ώστε ο νέος παίκτης
να έχει πάντα δουλειά. Οι AI θέσεις:

- πληρώνουν **στο κάτω άκρο** της αγοράς (πρόταση: 80% της μέσης τιμής παικτών),
- προσφέρουν μόνο entry-level ρόλους,
- και **παύουν** να δημοσιεύονται όταν οι διαθέσιμες θέσεις παικτών ξεπερνούν
  ένα κατώφλι (πρόταση: 1.5 ανοιχτές θέσεις ανά άνεργο χαρακτήρα).

Αυτό είναι το κύριο εργαλείο ισορροπίας μεταξύ «ο νέος παίκτης έχει τι να
κάνει» και «οι παίκτες-εργοδότες βρίσκουν προσωπικό».
