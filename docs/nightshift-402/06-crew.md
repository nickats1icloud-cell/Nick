# 06 — Crew & κοινό γκαράζ

Το crew είναι **κοινή αγωνιστική οντότητα με δικό της ταμείο και δικά της
έξοδα** — όχι διακοσμητικό menu με λογότυπο.

## Δομή

| Πεδίο | Νόημα |
| ----- | ----- |
| Crew name | μοναδικό, δημόσιο |
| Members & ειδικότητες | ποιος είναι mechanic, driver, spotter, logistics manager, co-owner |
| Skill | ανά μέλος και ανά ειδικότητα, από XP και ιστορικό |
| Morale | ανεβαίνει με νίκες και εμπρόθεσμη πληρωμή, πέφτει με ήττες και χρωστούμενα |
| Chemistry | πόσο καιρό δουλεύουν μαζί· μπόνους στο `crew_quality` |
| Ποσοστά ιδιοκτησίας | αθροίζουν στο 100%· καθορίζουν μοιρασιά επάθλων |
| Permissions | garage, funds, events, team |
| Shared garage balance | κοινό ταμείο |
| Εβδομαδιαίο ενοίκιο | πάγιο, χρεώνεται αυτόματα |
| Crew payroll | οι πληρωμές των μελών ανά αγώνα |
| Αναβαθμίσεις εγκαταστάσεων | χωρητικότητα αυτοκινήτων, εξειδικευμένος εξοπλισμός |

## Ποσοστά και μοιρασιά

Τα ποσοστά ιδιοκτησίας ορίζονται στη δημιουργία και αλλάζουν **μόνο με
συναίνεση όλων των μελών που θίγονται**. Τα έπαθλα μοιράζονται:

```
έπαθλο → crew payroll (σταθερές αμοιβές μελών για τον αγώνα)
       → έξοδα αγώνα (entry, καύσιμο, φθορά)
       → υπόλοιπο × ποσοστά ιδιοκτησίας
```

Πρώτα πληρώνονται οι άνθρωποι, μετά οι ιδιοκτήτες. Αν το έπαθλο δεν καλύπτει
το payroll, η διαφορά βγαίνει από το shared balance· αν ούτε αυτό φτάνει, το
crew μπαίνει σε **χρέος** και το morale πέφτει.

## Permissions

| Flag | Επιτρέπει |
| ---- | --------- |
| `garage.use` | να βάλει/βγάλει αυτοκίνητο από το κοινό γκαράζ |
| `garage.upgrade` | αναβαθμίσεις εγκαταστάσεων |
| `funds.view` / `funds.spend` | το shared balance |
| `events.enter` | δήλωση συμμετοχής στο όνομα του crew |
| `team.invite` / `team.kick` | διαχείριση μελών |

**Απαίτηση ασφάλειας:** καμία ενέργεια με χρήματα ή αυτοκίνητα χωρίς έλεγχο
flag στον server και εγγραφή στο audit. Το πιο συνηθισμένο παράπονο σε RP
servers είναι «μου άδειασαν το ταμείο του crew» — πρέπει να είναι αδύνατο
χωρίς ίχνος.

## Ενοίκιο και χρέος

Το εβδομαδιαίο ενοίκιο είναι ο βασικός sink του crew layer. Αν δεν πληρωθεί:

1. Ημέρα 1-3: προειδοποίηση, morale ↓.
2. Ημέρα 4-7: το γκαράζ κλειδώνει — τα αυτοκίνητα είναι μέσα αλλά δεν βγαίνουν.
3. Ημέρα 8+: κατάσχεση της χαμηλότερης αξίας αυτοκινήτου για κάλυψη του χρέους.

Σκληρό, αλλά είναι το μόνο που κάνει το ενοίκιο πραγματικό κόστος αντί για
προαιρετική συνδρομή.

## Multiplayer

Στο πραγματικό multiplayer, διαφορετικοί παίκτες μπορούν να είναι mechanic,
driver, spotter, logistics manager ή co-owner **του ίδιου crew** — με
διαφορετικά permissions και διαφορετικό ρόλο στο αποτέλεσμα του αγώνα. Το
`crew_quality` που μπαίνει στη συνάρτηση του αγώνα ([05](05-motorsport.md))
αθροίζει τα πραγματικά skills αυτών των ανθρώπων.

Στο local prototype τα μέλη είναι AI με σταθερό skill και morale — ίδιο schema,
`is_ai = true`.
